# Hero image placeholders

These two SVGs are temporary abstract image studies, not photographs, client work, or logos. Both are explicitly labeled as image placeholders in the hero.

To use your own photographs:
1. Put the image files in this folder.
2. Update the `src` values in `src/components/Hero.tsx`.
3. Remove the visible placeholder labels and temporary-image note when real images are in place.
4. If a photograph conveys information beyond decoration, supply appropriate `alt` text. The current decorative images have empty alt text; each capsule link has an accessible name.

The capsule masks, hover effects, focus styles, and responsive sizes are in the editorial hero block in `src/app/globals.css`. The original logo/header mark is unchanged. Colors are sampled visually from `01 Direção.pdf`; its board provides no written hexadecimal palette specification.
